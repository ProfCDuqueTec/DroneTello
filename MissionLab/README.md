# ¿Qué es MissionLab?
Es un entorno web que permite hacer unas primeras aproximaciones al control de operaciones de vuelo del DJI Tello con python.
Hay dos versiones: 
  - V1.0 es para una misión simple
  - V2.0 es para 5 misiones más complejas
  - V3.0 es para 5 misiones de captura de imagenes
Para utulizar cada MissionLab, debes descargar y ejecutar en un navegador (se probado con Google Chrome)
