Cómo completar la misión

  1. Agrega DESPEGAR; después elige AVANZAR, GIRAR, SUBIR, BAJAR o ESPERAR. Finaliza con ATERRIZAR.
  2. Usa los botones ↑ y ↓ para cambiar el orden de bloques. La secuencia se valida después de cada cambio.
  3. Pulsa Simular misión y observa la ruta trazada. Corrige errores de rumbo, obstáculos o punto de llegada.
  4. Diseña una segunda ruta en Alternativa B. Compara las dos opciones.
  5. Cuando el facilitador active la alerta, vuelve a simular: tal vez debas rediseñar tu misión.
  6. Exporta el plan JSON o el Python para que el profesor lo revise. El archivo Python solo simula por defecto.

Mecatrónica conecta la electrónica, programación, mecánica y control; industrial, computación, ciencia de datos y otras ingenierías complementan la misión.
